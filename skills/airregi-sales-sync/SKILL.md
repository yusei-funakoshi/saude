# Airレジ売上 → スプレッドシート転記スキル

対象日の Airレジ売上を**直営3店舗（神戸・梅田・心斎橋）**ぶん取得し、**税抜額（売上合計 − 内消費税等）**を各店舗のスプレッドシートの実績(D列)に書き込む。

**実行時にAIは一切使わない。** 取得・店舗切替・書込はすべて決定論的な CLI（`src/index.js`）が行う。このスキルは「日付を決めて CLI を起動し、結果を報告する」だけを担う。

---

## 前提（初回のみ・各自セットアップ）

`README.md` の手順で以下が済んでいること:

1. `config.json` を作成（AirID/パスワード/GAS URL/secret/stores）
2. `npm install`（playwright）+ `npx playwright install chromium`
3. GAS Web App をデプロイ（`gas/Code.gs`）し URL を config に設定

未セットアップなら、まず README に沿って整える。

---

## 起動手順（決定論的）

ユーザー発話から対象日を決める:

- 日付の指定がある（「5月23日」「2026-05-23」）→ `YYYY-MM-DD` に正規化
- 指定がない（「今日の」「売上を反映して」）→ **引数を渡さない**（CLI が当日 JST を使う）

スキルディレクトリで CLI を実行する:

```bash
cd <このスキルのディレクトリ> && node src/index.js [YYYY-MM-DD]
```

例:
- 当日: `node src/index.js`
- 指定日: `node src/index.js 2026-05-23`

---

## 結果報告

CLI の標準出力（店舗別の ✓/✗）をそのままユーザーに報告する。終了コード 0=全店舗成功、1=1店舗以上失敗。

```
  ✓ 2026-05-23 saude 神戸店   税抜 ¥116,927 (¥126,250 − 税¥9,323) → 実績(D) 書込完了 (行 145)
  ✓ 2026-05-23 saude 梅田店   税抜 ¥194,802 (...) → 実績(D) 書込完了 (行 145)
  ✓ 2026-05-23 saude 心斎橋店 税抜 ¥51,807  (...) → 実績(D) 書込完了 (行 145)
```

✗ が出たら、その行のエラーメッセージ（認証切れ／行未検出／secret不一致 等）をユーザーに伝える。`--headful` を付けるとブラウザ表示で原因を確認できる。

---

## やらないこと

- 売上の数値をスキル（Claude）側で計算・加工しない（CLI が算出）
- config やパスワードを出力・ログに残さない
- 失敗時に勝手にリトライを繰り返さない（原因を報告して指示を仰ぐ）
