# 発注計算（order-calc）

予測（アサイーボウル杯数 or 売上円）と現在在庫を入力すると、全品目の発注数を算出する単一ページツール。
発注シート「【④全店】運営サポート（発注シート）」の計算を移植したもの。

## 使い方

1. `index.html` を開く
2. 予測を入力（「杯数」or「売上(円)」→ 客単価で杯数換算）
3. 発注スパン（1日分 / 2日分）を選ぶ
4. 必要なら「現在の在庫を入力する」を開いて在庫を入れる（未入力＝0）
5. 「発注数を計算」→ 発注リスト表示。「テキストでコピー」で発注メモに使える

赤字＝発注が必要な品。資材は最低在庫まで補充する数（1日/2日で変わらない）。

## ホスティング

ES モジュール（`calc.js` / `recipe.js`）を読むため、**サーバー経由（http/https）で配信**して使う（他の saude ツールと同様）。`file://` で直接開くと一部ブラウザで読み込みに失敗する。ローカル確認は `python3 -m http.server` 等で。

## テスト

```bash
cd order-calc && node --test
```

`calc.test.js` が、食数50・在庫0 のとき発注シートの表示値（1日分・2日分）に一致することを全品で検証する。

## レシピ定数の更新

`recipe.js` の `RECIPE` が品目ごとの算出定数（出典＝発注シートの各セル数式）。発注シートを更新したら、対応する係数・しきい値・最低在庫を更新する。

## 発注シートから移植する際に見つけた点（要確認）

- **在庫参照のずれ**: 元シートの「無調製豆乳」「スムージーのはちみつ」の1日分セルは、隣の行の在庫を参照していた（off-by-one）。本ツールは各品が自分の在庫を引く正しい形に正規化した。
- **2日分の固定セル**: 一部の2日分セルは固定値で食数に追従しなかった。本ツールは係数化して食数に追従させた（食数50では元の表示値に一致）。
- **2日分の係数**: 品目ごとに ×1.5 / ×2 / バッファ計算 等が混在。元シートの定義を踏襲した。会議で「2日分」の定義を統一するか要確認。
